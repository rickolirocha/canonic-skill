# ICM Anti-Patterns

Detect and report these with evidence:

- permanent `misc/`, `general/`, `other/`, or `temp/` dumps;
- folders organized only by file extension;
- multiple files competing for authority;
- client context inside global skills;
- stable references mixed with current outputs;
- original sources modified without preservation;
- stages without outputs;
- stages with multiple primary transformations;
- one agent per stage without real isolation need;
- huge files loaded completely without section guidance;
- invisible dependencies;
- state kept only in chat;
- unversioned outputs;
- missing review gates for critical decisions;
- automation that hides the process;
- infrastructure before any real execution;
- outdated documents still treated as current;
- divergent copies of the same rule;
- beautiful structure without correspondence to real work.
